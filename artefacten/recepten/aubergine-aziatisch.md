# Aubergine — Aziatisch geïnspireerd

## Ingrediënten

*Voor 2 personen*

| Ingrediënt | Hoeveelheid |
|---|---|
| Aubergine* | 1 stuk |
| Bosui* | 1 bosje |
| Hoisinsaus | 50 g |
| Zoete Aziatische saus* | 35 g |
| Sojabonen* | 100 g |
| Komkommer* | ½ stuk |
| Ongezouten pindas | 20 g |
| Verse koriander* | 10 g |
| Knoflookteen | 1 stuk |
| Witte langgraanrijst | 150 g |
| Gomasio | 1 zakje |

*\* in de koelkast bewaren*

### Zelf toevoegen

| Ingrediënt | Hoeveelheid |
|---|---|
| Zoutarme groentebouillon | 360 ml |
| Zonnebloemolie | 60 ml |
| Water | naar behoefte |
| Wittewijnazijn | 2 tl |
| [Plantaardige] mayonaise | 2 tl |
| [Plantaardige] roomboter | naar smaak |
| Honing [of plantaardig alternatief] | naar smaak |

---

## Voedingswaarden

*Per portie:* Energie 3096 kJ / 740 kcal · Vetten 31 g · Waarvan verzadigd 7,5 g
